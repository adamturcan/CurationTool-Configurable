CurationTool-Configurable

A configurable data-curation platform for archival document annotation. This page aggregates the live application, programmer documentation, stakeholder testing materials, and the supporting design artefacts referenced across the thesis.

Open the application
Standalone-mode build hosted on GitHub Pages. Runs entirely in the browser and persists workspaces in localStorage; no backend required.
